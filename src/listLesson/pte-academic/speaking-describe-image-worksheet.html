PTE Academic – Speaking – Describe Image

CEFR Level: B2

Skill Focus: Structured Description of Visual Data

Question Type Reminder

Learning Objectives

The Task:

You will see an image (chart, map, diagram).

  • Prep time: 25 seconds
  • Speaking time: 40 seconds
  • Goal: Describe main features, not every detail.

By the end of this lesson:

  • ✅ Recognize chart types (Bar, Line, Pie, Map)
  • ✅ Identify key features (Highs, Lows, Trends)
  • ✅ Use accurate vocabulary (Increased, Stable, Majority)
  • ✅ Maintain fluency for 40 seconds

2. Warm-Up Activation

3. Strategy Focus

1. Identify Features

  • • Biggest / Smallest value
  • • Trends (Up/Down/Stable)
  • • Main Message

2. Vocabulary

  • ⬆️ Rose, Grew, Went up
  • ⬇️ Declined, Dropped
  • ➡️ Remained steady
  • 📊 Sharp, Gradual, Slight

3. Structure

  • Intro: What is it?
  • Body: 2-3 Key Features
  • Conclusion: Overall trend
