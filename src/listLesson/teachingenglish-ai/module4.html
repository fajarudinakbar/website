Interactive Learning Design with AI

Topic: Building Web-Based Learning Tools (Vibe Coding)

Instructions: You are moving from static materials to interactive systems. Complete the Preparation, learn the principles of Vibe Coding using Gemini Canvas, and plan your first interactive English language app.

Task 1 Reflection

Think about a static worksheet. It delivers tasks in a fixed order. How is an app different? What happens when a learner makes a choice in an app versus a worksheet?

Insight: A worksheet is static. An interactive tool allows for immediate feedback, branching outcomes, and higher learner agency. You are designing interaction logic, not just content.

Task 2 Key Terminology

Section 1. From Worksheet to Learning System

A worksheet delivers tasks in a fixed order. An interactive tool responds to learner choices. This allows:

  • Immediate feedback
  • Branching outcomes
  • Repeated practice without repetition
  • Higher learner agency

Section 2. What Is "Vibe Coding"?

Vibe coding means describing how an app should behave using natural language. The AI writes the code behind the scenes. You describe what learners see, what happens when they click, and how feedback works.

Section 3. The Pedagogical Rule Still Applies

Even though you are building an app, the starting point remains a GSE Can-Do statement. Your app must create interaction that requires this performance.

Example: "Can handle basic customer service questions in a shop."

Section 4. Types of ELT Apps You Can Build

  • Dialogue choice simulations
  • Branching role-play scenarios
  • Vocabulary decision games
  • Negotiation simulations

These are not games for entertainment. They are structured communicative systems.

Section 5. Mastering the Tool: Gemini Canvas

To build these apps effectively, you must use the Canvas feature in Gemini. Canvas provides a dedicated workspace where code is generated and previewed.

Setup Guide

1. Activating Canvas

Canvas often activates automatically when you ask for code. You can also explicitly trigger it by clicking the Canvas icon (usually top-left) or by starting your prompt with phrases like "Create a web app..." or "Write a python script...".

Prompt: "Open a canvas and create..."
2. Choosing the AI Model

In the model dropdown menu, you will typically see three options. Choosing the right one is critical for coding:

  • Fast (Flash): Best for quick text edits or simple brainstorming. Avoid for complex coding.
  • Thinking (Reasoning): Use this for complex logic or if your code has bugs. It "thinks" before it writes.
  • Pro (Gemini Pro): Recommended for Vibe Coding. The best balance of speed and capability for generating interactive apps.

Section 6. Prompting & Logic

Once you have selected Pro (recommended) or Thinking mode, use a prompt like this:

"You are an educational web app developer. Create a simple interactive web app for English learners. Learning objective: Learners can handle basic customer service questions in a shop. The app should show a customer question, offer three possible responses, and give feedback on the choice. After feedback, show the next situation."

Interaction Logic: Situation → Learner choice → Feedback → Next situation.
