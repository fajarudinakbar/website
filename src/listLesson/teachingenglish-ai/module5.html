Global Deployment and Professional Portfolio

Topic: Publishing Your Innovations Online

Instructions: This final module focuses on making your work visible. Complete the Preparation, learn how to use GitHub Pages, and build your professional Innovation Portfolio.

Task 1 Reflection

Why do most teachers' innovations stay inside the classroom? What is the benefit of making your work public and accessible online?

Insight: Digital deployment turns private materials into a Professional Portfolio. It provides evidence of innovation, shares resources with learners, and positions you as an educational innovator, not just a teacher.

Task 2 Key Terminology

Section 1. Why Deployment Matters

Traditionally, teaching expertise stays hidden. Digital deployment turns your work into:

  • A professional portfolio
  • Evidence of innovation
  • Shareable resources for learners
  • A demonstration of AI-integrated pedagogy

Section 2. What Is GitHub Pages?

GitHub Pages is a free service that allows you to host websites directly from your GitHub repository. You can publish interactive apps, lesson examples, and scenario packs without needing server management.

Section 3. Your Innovation Portfolio

Your portfolio should contain three key parts:

1. Teaching Approach

Explain your use of AI, pedagogy, and standards.

2. Sample Innovations

Items from Modules 1-4 (Lessons, Scenarios, Apps).

3. Pedagogical Explanations

Describe the learning problem each tool solves.

Section 4. Basic Steps to Publish

  1. Create a GitHub account (github.com).
  2. Create a new repository (e.g., ai-elt-portfolio).
  3. Upload your files (HTML apps, text descriptions).
  4. Enable GitHub Pages in settings.

Section 5. What to Write on Each Page

For every project you upload, answer these questions to show professional thinking:

• What learning objective does this address?

• Which GSE Can-Do statement guided design?

• What problem does this tool solve?

• How does AI support learning here?
